# 🔑 Caesar Cipher

A simple command-line program that encodes or decodes a message using the classic Caesar cipher, shifting each letter by a chosen number of positions.

---

## 🚀 How to run

Navigate to this folder and run the script directly with Python:

```bash
python3 cipher.py
```

You'll be prompted to:

1. Choose `encode` or `decode`
2. Enter your message
3. Enter a shift number
