## ☕ Coffee Machine

A command-line program designed to brew drinks, monitor available supplies and calculate change for transactions.

## ✨ Features

- Brews espresso, latte, or cappuccino.
- Tracks milk, water, and coffee bean levels automatically.
- Processes coin payments and calculates change.
- Provides status reports on inventory.
- Detects insufficient ingredients or payment.

## 🚀 How to get started

Navigate to this folder and run the script directly with Python:

```bash
python3 main.py
```
