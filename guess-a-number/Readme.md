# Number Guessing Game

A command-line game where players try to guess a secret number from 1 to 100 on easy or hard mode.

## ✨ Features

- Difficulty Levels:
  - easy: 10 attempts
  - hard: 5 attempts
- Prevents invalid inputs.
- Tells the user if their guess is "Too high" or "Too low" after every turn.

## 🚀 How to Run

Navigate to this folder and run the script directly with Python:

```bash
python3 main.py
```
