# 🃏 Blackjack Game

A simple command-line Blackjack game.

## ✨ Features

- Play vs. Computer dealer
- Unlimited card deck with equal draw probability
- Dynamic Ace valuation (switches 11 to 1 if score goes over 21)
- Dealer draws automatically until hitting 17 or higher
- Hidden dealer card during player turn
- Play multiple rounds continuously or exit

## 🚀 How to Run

Navigate to this folder and run the script directly:

```bash
python3 main.py
```
